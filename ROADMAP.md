# Roadmap

**Source of truth:** Goal issues in [WeGotWorkspace/Product](https://github.com/WeGotWorkspace/Product) (every issue there is a Goal), on the [Product roadmap](https://github.com/orgs/WeGotWorkspace/projects/1) Project. Status: Identified → Adopted → Fulfilled. Start at the Project — not the default Issues tab.

- **[0.9 Roadmap](https://github.com/orgs/WeGotWorkspace/projects/1/views/4)** — beta todo (`Adopted` + milestone `v0.9`)
- [All Goals](https://github.com/orgs/WeGotWorkspace/projects/1/views/1) — full map (`repo:WeGotWorkspace/Product`)
- [Open unfinished Goals](https://github.com/WeGotWorkspace/Product/issues?q=is%3Aissue+is%3Aopen)

Fulfilled Goals are **closed**. Board Status stays Fulfilled. Identified is a draft backlog — do not Adopt (or attach a milestone) until committing that outcome to a release.

How to browse (Goals vs delivery vs milestones): [docs/product/README.md](docs/product/README.md#how-to-browse). Board setup: [docs/product/project-setup.md](docs/product/project-setup.md).
