# Privacy notes

What WeGotWorkspace keeps and where. This page grows as features add data; each line says what is kept, where, and who can see it.

## On your device

- **Recent errors (Settings → Diagnostics).** The browser keeps the last 50 unexpected errors on this device: the error message and stack, the app, the page path (no query string or fragment), the build version, the browser's user agent, and the time. It keeps no request bodies and no document or file content. Nothing is sent anywhere: the list leaves the device only when you copy it, for example into a bug report. Signing out deletes it, together with the other offline data.
